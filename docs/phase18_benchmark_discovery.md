## Findings
1. The RSNA-derived sources (weak labels, hold-out, public LLM labels) share the same reports, labeler or studies as our training, so none is independent evidence of accuracy.
2. The 58 gold studies are independent of the weak labels but small (CI half-width about 0.1), were used to train the older baselines and to evaluate Models A and B, and must stay reserved for a single final look.
3. **MRNet is the only locally available labelled MRI set that is (a) separate from RSNA, (b) labelled by clinicians rather than by our extractor or an LLM, (c) large enough for a useful interval (120 to 1,250 exams) and (d) never used to train C0, B0 or C1.**
   Limits: it labels meniscus tear as one category, so Medial and Lateral Meniscus outputs would need a pre-declared combination (for example the larger of the two probabilities, fixed in advance); its sequences and plane protocol differ from RSNA (cross-domain transfer, so a low score could reflect
   domain shift rather than a poor model); its valid split was used to select the older MRNet-pretrained model, so only claims about the C0 family are clean; its use terms must be checked (a research-use agreement normally forbids re-uploading, which would rule out a Kaggle run).
4. Inference needs no GPU: scoring a preserved checkpoint on 1,250 exams (about 34,000 images at 128 px) is a forward pass that should take a few minutes on this CPU, so MRNet evaluation can be done locally, subject to the licence.
5. Candidates not on this machine (not downloaded, no network use here; details unverified): other public knee-MRI sets with ACL / meniscus labels exist (for example a Croatian ACL set, fastMRI+ annotations, OAI/SKI10); each would need a licence, label-provenance and overlap check before use.

## Suggested next steps (for decision; nothing started)
1. Confirm MRNet's licence and label provenance from its documentation; keep it local.
2. Pre-register the evaluation: checkpoints B0 / C1 (seed 201), the Phase 16 seed-101 and Phase 15 real-label checkpoints; targets ACL and "meniscus = max(Medial, Lateral)"; metrics AUC with bootstrap CI; paired comparison against a metadata-only model using MRNet-available metadata (shape, slice counts) and against untrained and shuffled-label controls; the plane/sequence mismatch recorded as a limitation.
3. Write an MRNet-to-C0 input adapter that reproduces the RSNA preprocessing (per-slice 1-99 percentile normalisation, bilinear resize to 128, up to 9 evenly spaced slices, plane order Axial / Coronal / Sagittal) with tests, then run inference locally on CPU.
4. Keep the 58 gold studies for one final look after a candidate is frozen.
