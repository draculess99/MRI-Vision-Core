## Proposed Controlled Offline Pilot

### Pilot Scope
**Sample Size**: 25 real RSNA reports (subset of 4,407 available)  
**Reference Labels**: 25 from the 58 gold-labeled studies (if no leakage confirmed)  
**Targets**: ACL, Medial Meniscus, Lateral Meniscus (3 of 12)  
**Processing**: Rule-based extractor (offline, deterministic)  

### Selection Method
1. **Leakage verification**: Compare 58 gold study IDs against Phase 19D training/validation IDs
2. **Stratified sampling**: Select 25 from 58 gold labels, stratified by class (positive/negative)
3. **Deterministic seed**: Use fixed random seed for reproducibility
4. **Conservative approach**: If any gold labels overlap Phase 19D, exclude them

### Input Requirements
- **Real reports**: `data/rsna-knee/train.csv` Report column ✅ **Available**
- **Reference labels**: `data/rsna-knee/train.csv` ACL/Medial Meniscus/Lateral Meniscus columns ✅ **Available**
- **No new downloads**: All local ✅ **No external access**
- **Phase 19D IDs**: May need to extract from checkpoint to verify no leakage

### Processing Workflow (Read-Only)
```
1. Load 25 real reports + gold labels from train.csv
2. Run three-agent pipeline on each:
   - Extractor: extract findings + evidence spans
   - Verifier: validate claims against source text
   - Adjudicator: reconcile and escalate uncertainty
3. Collect results (no modifications to source data)
4. Compare agent predictions vs gold labels
5. Measure: accuracy, uncertainty preservation, evidence quality
```

### Output Location
```
outputs/phase20c_pilot/
├── pilot_sample_selection.json
├── agent_predictions.jsonl
├── accuracy_metrics.json
├── per_target_performance.json
├── escalation_summary.json
├── error_analysis.json
└── phase20c_pilot_report.md
```

### Leakage & Privacy Checks (Before Pilot)
- [ ] Verify 58 gold study IDs against Phase 19D training IDs (no overlap required)
- [ ] Verify 58 gold study IDs against Phase 19D validation IDs (no overlap required)
- [ ] Confirm 25-sample selection is deterministic (fixed seed)
- [ ] Log sample selection decisions (for audit trail)
- [ ] No report text or patient IDs in output files
- [ ] Aggregate metrics only (per-target accuracy, not individual study results)

### Comparison Metrics
**Per-target (3 targets)**:
- Accuracy: Agent label == Gold label
- Precision/Recall: Agent positive vs gold positive
- False negative rate: Agent NEGATIVE when gold POSITIVE
- Uncertainty escalation: % of cases where agent says UNCERTAIN

**Aggregate**:
- Accuracy: mean per-target
- Anatomical confusion: Medial vs Lateral errors
- Evidence quality: % of findings with source spans
- Abstention rate: % escalated for human review

### Important Caveats

⚠️ **Synthetic tests do not establish accuracy**: 
- Phase 20B passing 37/37 tests validates agent *logic* and *architecture*, not accuracy on real medical language
- Gold-label comparison provides first accuracy measurement on real data

⚠️ **Three targets only**:
- Phase 20C focuses on 3 targets (Phase 19D scope)
- Full 12-target pilot would be Phase 21+

⚠️ **Rule-based limitations**:
- Current system uses rule-based extractor (lexical only)
- Does not handle complex negation or long-range coreference
- This is EXPECTED and documented
